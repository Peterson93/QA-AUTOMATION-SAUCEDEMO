# QA Automation Project - SauceDemo

Automatización de pruebas end-to-end usando Python, Selenium y pytest sobre la aplicación SauceDemo.

## Tecnologías
- Python
- Selenium
- pytest

## Casos de prueba implementados
- Login válido
- Login inválido
- Agregar producto al carrito
- Validación de producto en carrito

## Evidencia
El proyecto incluye captura automática de pantalla cuando ocurre un fallo.

## CI/CD
El proyecto ejecuta pruebas automáticamente usando GitHub Actions en cada push.

## Screenshots automáticos
Cuando un test falla, se captura evidencia automáticamente.

## Tipos de pruebas
- Pruebas funcionales
- Pruebas negativas
- Flujo End-to-End (E2E)
